Buzz test — say the song

This is the one part of the buzzer round that has never been tested on a real phone: speaking an answer and having it marked. No Spotify, no room, no other players — just this. Open it on the phone you would actually play on.

Wonderwall
by Oasis

What to try
  1. Say the song and the artist — should score both
  2. Say only the song — should score half
  3. Say it sloppily: "erm, is it Wonderwall by Oasis?" — should still score both
  4. Say something wrong — should score nothing
  5. Try it with the telly on, to see how it copes with noise

Whatever it heard is shown in quotes, so if it marks you wrong you can see whether the phone misheard you or the marking was too strict. That is the thing I need to know before this goes back in the game.
